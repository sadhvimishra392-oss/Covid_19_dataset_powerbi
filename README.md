# 🦠 COVID-19 Data Analysis Dashboard

A Power BI dashboard project developed to analyze global COVID-19 data and uncover trends related to confirmed cases, recoveries, and deaths. The dashboard provides interactive visualizations that help users understand the spread and impact of the pandemic across different regions.

---

## 📌 Project Overview

This project focuses on analyzing COVID-19 data using Power BI to gain insights into infection rates, recovery trends, and mortality statistics.

The dashboard enables users to:

- Monitor total COVID-19 cases
- Analyze recovery and death rates
- Compare affected regions
- Identify trends in case growth
- Explore pandemic-related insights through interactive visualizations

---

## 🎯 Objectives

- Track the global impact of COVID-19
- Analyze confirmed, recovered, and death cases
- Compare case distribution across regions
- Visualize recovery and mortality trends
- Support data-driven understanding of pandemic patterns

---

## 🛠️ Tools & Technologies Used

- Power BI Desktop
- Power Query

- Data Modeling
- Data Visualization

---

## 📊 Dashboard Pages

### 1. Global COVID-19 Overview
Provides a high-level summary of the pandemic, including key metrics and overall trends.

### 2. Case Distribution Analysis
Analyzes the distribution of confirmed cases across different regions and countries.

### 3. Recovery & Death Analysis
Examines recovery rates, death rates, and the relationship between confirmed, recovered, and fatal cases.
